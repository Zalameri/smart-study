# SmartStudy

SmartStudy is a student productivity web application designed to help students organize courses, schedules, chapters, notes, quizzes, and study progress in one place.

## Features

- User registration and login
- Course management
- Weekly study schedule
- Chapter and note organization
- Quiz pages
- Study settings
- Data saving per user
- Responsive web interface
- PHP backend
- MySQL database integration

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- PDO
